Casio fx-991CE X (ClassWiz) pro test z PSO

Co z testu kalkulačka spočítá sama a jak se k tomu dostat. Ukázky jsou úlohy ze sad, takže si výsledek můžeš ověřit. Názvy položek menu jsou uvedené anglicky; když máš menu česky, hledej stejnou položku v překladu. Na papíře musí být vždy vzorec a dosazení, kalkulačka slouží ke kontrole.

1 · Nastav před testem

Radiány! Jinak vyjdou integrály se sin a cos špatně

SHIFT MENU (SETUP) → Angle Unit → Radian. Výchozí jsou stupně: \(\int_0^\pi \frac12 \sin x\,dx\) pak nevyjde 1 (S4/5). Kontrola: \(\sin(\pi/2)\) musí dát 1.

ČetnostiSHIFT MENU → Statistics → Frequency → On. Ve statistice přibude sloupec Freq (data s četnostmi, EX z tabulky).
ZobrazeníSETUP → Input/Output → MathI/MathO (zlomky a odmocniny jako na papíře). Zlomek ↔ desetinné číslo: S⇔D.
ResetKdyž se něco chová divně: SHIFT 9 (RESET) → Setup Data. Pak znovu nastav Radian a Frequency.

Tři pasti
  • CD na kalkulačce je \(p(X \le x)\), ale \(F(x)\) v kurzu je \(p(X < x)\). Pro diskrétní X: \(p(X < 3) = \text{CD}(x = 2)\); at least 3 = \(1 - \text{CD}(2)\).
  • Normal CD i Inverse Normal chtějí σ, ne rozptyl, a σ se zadává před μ.
  • Inverse Normal bere plochu vlevo: \(p(X > x) = 0{,}01\) → Area = 0,99. Symetrické meze s pravděpodobností γ: Area = \((1 + \gamma)/2\) dá horní mez, Area = \((1 - \gamma)/2\) dolní.

Výsledky z kalkulačky se od výsledků ze sad můžou lišit v tisícinách (sady počítají s kvantily zaokrouhlenými z tabulky, např. u = 1,15 místo 1,1503). To je v pořádku.

4 · Statistika z dat: MENU → Statistics

Průměr a směrodatná odchylka (intervaly, t-testy)

  1. MENU → Statistics → 1-Variable.
  2. Do sloupce x zadávej hodnoty, každou potvrď =.
  3. OPTN → 1-Variable Calc: \(\bar{x}\), \(\sum x\), \(\sum x^2\), \(\sigma_x\) (dělí n), \(s_x\) (dělí n − 1), n.
  4. Do intervalů a testů patří \(s_x\).

Ukázka S7/2 (1,04; 1,03; …; 1,05): \(\bar{x} = 1{,}0367\), \(s_x = 0{,}01414\). Párový test (S8/2): zadej rovnou rozdíly 5, 2, 18, −1, 3, −1, 6 → \(\bar{x} = 4{,}571\), \(s_x = 6{,}503\).

Data s četnostmi (χ² test, EX z tabulky)

  1. Zapni Frequency (oddíl 1). Ve sloupci x jsou hodnoty nebo středy tříd, ve sloupci Freq četnosti \(n_j\).
  2. OPTN → 1-Variable Calc. S8/3: \(\bar{x} = 4{,}338 = \lambda\), n = 71. S8/5 (středy 2,5 … 27,5): \(\bar{x} = 15{,}8\), \(\sigma_x = 6{,}716\), \(s_x = 6{,}750\).
  3. EX a DX diskrétní veličiny: do Freq dej pravděpodobnosti, pak \(\bar{x} = EX\), \(\sigma_x^2 = DX\) (n = 1). S2/5: \(\bar{x} = 1{,}03\), \(\sigma_x^2 = 1{,}4291\). Kdyby kalkulačka nebrala desetinné četnosti, vynásob všechny stem; výsledek se nezmění.

Regresní přímka (S8/6)

  1. MENU → Statistics → y=a+bx.
  2. Sloupec x (věk), sloupec y (úspěšnost); šipkami přepínáš sloupce.
  3. OPTN → Regression Calc: a = 0,2453 (absolutní člen), b = 0,000465 (směrnice), r = 0,0555. Součty \(\sum x\), \(\sum xy\), … najdeš v OPTN → 2-Variable Calc.
