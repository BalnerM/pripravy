Fráze: exactly k \(X=k\) · at least k \(X\ge k = 1-p(X\le k-1)\) · at most / not more than \(X\le k\) · more / less than \(>,<\) · none \(X=0\) · at least one \(1-p(0)\) · either A or B \(A\cup B\) · given that \(p(\cdot\mid\cdot)\) · with / without replacement → Bi / H · confidence 0,95 → α = 0,05 · significance level 95 % (S8/3) → α = 0,05.

1 · Klasická pravděpodobnost

  1. Jeden výsledek = co přesně padne / se vytáhne. Kostky = uspořádaná dvojice (36), i „two same dice“. Tah k karet naráz = k-tice bez pořadí.
  2. Všechny výsledky n: k z n bez pořadí \(\binom{n}{k}\) (nCr) · s pořadím \(\frac{n!}{(n-k)!}\) (nPr) · s vracením \(n^k\) · seřazení \(n!\).
  3. Příznivé m počítej stejným způsobem jako n. j dobrých z M a zbytek z ostatních: \(\binom{M}{j}\binom{N-M}{k-j}\).
  4. \(p = m/n\). „Aspoň jeden“ → \(1 - p(\text{žádný})\). Tahy po jednom bez vracení → násob zlomky \(\frac{4}{32}\cdot\frac{3}{31}\).

\(p(\bar A) = 1 - p(A)\) · \(p(A \cup B) = p(A) + p(B) - p(AB)\) · \(p(A \mid B) = \frac{p(AB)}{p(B)}\) · nezávislé: \(p(AB) = p(A)\,p(B)\)

S1/5 2 kola po 3 míčcích (9 nových, 6 hraných; v 1. kole j nových, ve 2. k nových): \[ p(k) = \sum_j \frac{\binom{9}{j}\binom{6}{3-j}}{\binom{15}{3}}\cdot\frac{\binom{9-j}{k}\binom{6+j}{3-k}}{\binom{15}{3}} \]

2 · Geometrická pravděpodobnost

  1. Každé náhodné číslo = jedna osa (x, y). Ω = čtverec / obdélník, spočítej jeho plochu.
  2. Každou podmínku přepiš na „y < …“: \(x+y<1\) → \(y<1-x\); \(xy<c\) → \(y<c/x\); reálné kořeny → \(D \ge 0\).
  3. Nakresli hranice a vyšrafuj, kde platí všechny podmínky.
  4. Průsečíky hranic (rovnice; Polynomial).
  5. Plocha = \(\int (\text{horní} - \text{dolní})\,dx\), po úsecích mezi průsečíky.
  6. \(p = \) plocha / plocha Ω. Kruh: poměr \(r^2\).

S1/9 \(x+y<1\), \(xy<0{,}09\): průsečíky 0,1 a 0,9; \(\int_0^{0{,}1}(1-x) + \int_{0{,}1}^{0{,}9}\frac{0{,}09}{x} + \int_{0{,}9}^1 (1-x) = 0{,}298\).

3 · Úplná pravděpodobnost, Bayes

  1. Hypotézy \(H_i\) = odkud věc je (skupina, krabice, stroj). Zapiš \(p(H_i)\); součet musí být 1 (účasti 60/50/70 % → \(p(H_1) = 0{,}6/1{,}8\)…).
  2. Zapiš \(p(A\mid H_i)\) = pravděpodobnost jevu A uvnitř skupiny i.
  3. Úplná p.: pro každou větev \(p(H_i)\cdot p(A\mid H_i)\), pak sečti.
  4. Bayes („A nastalo, z které skupiny?“): moje větev / součet z kroku 3.
\[ \begin{aligned} p(A) &= \sum_i p(H_i)\,p(A\mid H_i) \\ p(H_k\mid A) &= \frac{p(H_k)\,p(A\mid H_k)}{p(A)} \end{aligned} \]

A dřív než B (opakuji, dokud nenastane A nebo B): \(\frac{p(A)}{p(A)+p(B)}\), S1/4: \(\frac{4}{4+6}\). Střídání, začíná A, zásah a / b: \(p_A = \frac{a}{1-(1-a)(1-b)}\). Monty Hall: změnit → 2/3. HW2/2 s \(p(N=k)\): Bayes přes všechna k, \(\sum \frac{x^k}{k!} = e^x\).

4 · Diskrétní náhodná veličina

  1. Tabulka \(x_i \mid p_i\), kontrola \(\sum p_i = 1\). Dvě neznámé p: \(\sum p_i = 1\) a \(\sum x_i p_i = EX\) → Simul.
  2. F(x) = p(X < x) po intervalech: \(x \le x_1\): 0 · \(x_1 < x \le x_2\): \(p_1\) · \(x_2 < x \le x_3\): \(p_1+p_2\) · … · za \(x_{\max}\): 1.
  3. Z F zpět: \(p(X=k)\) = skok v k · \(p(X<a) = F(a)\) · \(p(X\ge a) = 1 - F(a)\) · \(p(a\le X<b) = F(b) - F(a)\).
  4. EX, DX (kalkulačka: Statistics, Freq = \(p_i\) → \(\bar x\) = EX, \(\sigma_x^2\) = DX):
\[ \begin{aligned} EX &= \textstyle\sum x_i p_i, \qquad EX^2 = \sum x_i^2 p_i \\ DX &= EX^2 - (EX)^2, \qquad \sigma = \sqrt{DX} \end{aligned} \]

\(E(aX+b) = aEX + b\) · \(D(aX+b) = a^2 DX\) · \(E(X+Y) = EX+EY\); nezávislé \(D(X+Y) = DX+DY\)

S2/1 do 1. červené (3 b, 2 č): \(p(1) = \frac25\), \(p(2) = \frac35\cdot\frac24\), \(p(3) = \frac35\cdot\frac24\cdot\frac23\), \(p(4) = \frac35\cdot\frac24\cdot\frac13\cdot 1\). S2/3 F skočí v 10 z 0,3 na 0,6 → \(p(10) = 0{,}3\); \(p(X<10) = F(10) = 0{,}3\).

  2. Otázku přepiš na X: exactly k → \(p(X=k)\); at most k → \(p(0)+\dots+p(k)\); at least k → \(1 - p(X\le k-1)\).
  3. Dosaď do vzorce nebo kalkulačka: Binomial / Poisson PD = \(p(X=x)\), CD = \(p(X\le x)\).

6 · Spojitá náhodná veličina

  1. Konstanta a: \(\int f\,dx = 1\) přes úsek, kde \(f \ne 0\) → rovnice pro a. „Prove density“: \(f \ge 0\) a \(\int f = 1\).
  2. Pravděpodobnost: \(p(a<X<b) = \int_a^b f\,dx\) (< a ≤ je jedno).
  3. F(x) po částech: vlevo od úseku 0 · na úseku \(\int_{\text{začátek}}^{x} f(t)\,dt\) · vpravo 1. Kontrola: na hranicích navazuje.
  4. EX, DX: \(EX = \int x f\), \(EX^2 = \int x^2 f\), \(DX = EX^2 - (EX)^2\). Symetrická f → EX = střed.
  5. Medián / kvantil: vyřeš \(F(\tilde x) = 0{,}5\) / \(F(x_p) = p\) (SOLVE).

S4/4 \(f = a(3x - x^2)\) na ⟨0, 3⟩: \(a\cdot\frac92 = 1\) → \(a = \frac29\); \(F = \frac{x^2}{3} - \frac{2x^3}{27}\) na ⟨0, 3⟩.

rovnoměrné ⟨a, b⟩\(f = \frac{1}{b-a}\)\(EX = \frac{a+b}{2}\), \(DX = \frac{(b-a)^2}{12}\)
exponenciální\(f = \lambda e^{-\lambda x}\), \(F = 1 - e^{-\lambda x}\)\(\frac1\lambda\); \(\frac{1}{\lambda^2}\)
Laplace\(f = \frac\lambda2 e^{-\lambda|x|}\)0; \(\frac{2}{\lambda^2}\)

Integrály: \(\int x^n = \frac{x^{n+1}}{n+1}\) · \(\int e^{ax} = \frac{e^{ax}}{a}\) · \(\int \frac1x = \ln|x|\) · per partes \(\int uv' = uv - \int u'v\) · \(\int x\sin x = \sin x - x\cos x\) · \(\int x\cos x = \cos x + x\sin x\) · \(\int x^2\sin x = -x^2\cos x + 2x\sin x + 2\cos x\) · \(\int x^2\cos x = x^2\sin x + 2x\cos x - 2\sin x\) · \(\int x e^{-\lambda x} = -\frac{e^{-\lambda x}}{\lambda^2}(\lambda x + 1)\) · \(\int x^2 e^{-\lambda x} = -\frac{e^{-\lambda x}}{\lambda^3}(\lambda^2x^2 + 2\lambda x + 2)\) · \(|x|\): rozděl na \(x<0\), \(x>0\) (sudá f → \(2\int_0^\infty\)). Číselně: ∫ na kalkulačce (Radian!).

7 · Normální rozdělení No(μ, σ)

A) Hodnota x → pravděpodobnost

  1. Zapiš μ a σ (σ = √variance!).
  2. Normuj: \(u = \frac{x-\mu}{\sigma}\) (na 2 desetinná místa pro tabulku).
  3. \(p(X<x) = \Phi(u)\) · \(p(X>x) = 1-\Phi(u)\) · \(p(a<X<b) = \Phi(u_b) - \Phi(u_a)\) · záporné u: \(\Phi(-u) = 1 - \Phi(u)\).

B) Pravděpodobnost → hodnota x

  1. Převeď na tvar \(p(X<x) = p\): above x with prob. 0,01 → \(p = 0{,}99\); below with 0,02 → \(p = 0{,}02\).
  2. Kvantil \(u_p\) z tabulky; pro \(p < 0{,}5\): \(u_p = -u_{1-p}\).
  3. \(x = \mu + \sigma u_p\). Symetricky kolem μ s pravděpodobností γ: \(\mu \pm \sigma\,u_{(1+\gamma)/2}\).

Kalkulačka: Normal CD (Lower, Upper, σ, μ) · Inverse Normal (Area vlevo). 3σ: 68,3 / 95,4 / 99,7 %. Nakresli zvon a vyšrafuj plochu.

S5/5 chyba No(1; 0,3), hranice s 1 % nad ní: \(1 + 0{,}3\,u_{0{,}99} = 1 + 0{,}3\cdot 2{,}326 = 1{,}698\); 75 % symetricky: \(1 \pm 0{,}3\,u_{0{,}875} = 1 \pm 0{,}3\cdot 1{,}150\).

8 · Limitní věty

Moivre–Laplace (počet úspěchů X ~ Bi(n, p), n velké)

  1. Ověř \(npq > 9\).
  2. \(\mu = np\), \(\sigma = \sqrt{npq}\) (relativní četnost X/n: \(\mu = p\), \(\sigma = \sqrt{pq/n}\)).
  3. Dál jako 7A: \(u = \frac{x - np}{\sqrt{npq}}\), Φ. Bez opravy na spojitost.

S6/1b n = 10000, p = 0,515: μ = 5150, σ = 49,98; \(p(X<5000) \approx \Phi(-3{,}00) = 0{,}00135\). S6/2 \(2\Phi(2) - 1 = 0{,}9544\).

CLV (součet / průměr n nezávislých)

  1. μ, σ jedné veličiny (hmotnost 1 osoby).
  2. Součet: \(\mu_S = n\mu\), \(\sigma_S = \sigma\sqrt n\) (ne nσ!) · průměr: μ, \(\sigma/\sqrt n\).
  3. Dál jako 7A.

8 · Limitní věty: hledání n, Čebyšev

Hledání n (kolik lidí / pokusů)

  1. Podmínku zapiš normovanou: \(\frac{4500 - 75n}{15\sqrt n} \ge u_{0{,}99} = 2{,}326\).
  2. Substituce \(z = \sqrt n\), roznásob: \(75z^2 + 2{,}326\cdot 15\,z - 4500 \le 0\).
  3. Polynomial → kladný kořen z; \(n = z^2\).
  4. Lidí zaokrouhli dolů, pokusů nahoru; ověř dosazením.

S6/4 \(75z^2 + 34{,}89z - 4500 = 0\) → \(z = 7{,}52\), \(z^2 = 56{,}5\) → n = 56 lidí.

Čebyšev: \(p(|X - EX| \ge \varepsilon) \le DX/\varepsilon^2\).

9 · Náhodný vektor (X, Y)

  1. Konstanta: \(\iint f\,dx\,dy = 1\).
  2. Marginální: \(f_X(x) = \int f(x,y)\,dy\) (integruj přes y), \(f_Y(y) = \int f(x,y)\,dx\).
  3. Nezávislost: platí \(f = f_X\,f_Y\) všude? Ano → nezávislé.
  4. p(G): nakresli oblast; vnější meze čísla, vnitřní závisí na vnější proměnné; spočítej vnitřní integrál první. Obdélník a \(f = g(x)h(y)\) → součin dvou integrálů.
  5. cov, ρ: \(E(XY) = \iint xy f\), \(\text{cov} = E(XY) - EX\,EY\), \(\rho = \frac{\text{cov}}{\sigma_X\sigma_Y}\).

S6/5d \(p(Y\le X) = \int_0^1\!\int_0^x 4x(1-y)\,dy\,dx = \int_0^1 (4x^2 - 2x^3)\,dx = \frac56\).

10 · Výběrové charakteristiky

\[ \bar x = \frac{\sum x_i}{n},\quad s^2 = \frac{\sum (x_i - \bar x)^2}{n-1} = \frac{\sum x_i^2 - (\sum x_i)^2/n}{n-1} \]

Kalkulačka: Statistics → 1-Variable → data → OPTN → 1-Variable Calc: \(\bar x\), \(s_x\) (= s, dělí n − 1), \(\sigma_x\) (dělí n). Četnosti \(n_j\) do sloupce Freq (středy tříd \(x_j\)): \(\bar x = \frac{\sum x_j n_j}{n}\), \(\sigma^2 = \frac{\sum x_j^2 n_j}{n} - \bar x^2\) (S8/5: 6,72).

11 · Interval spolehlivosti

  1. Ze zadání n, \(\bar x\), s (nebo z dat kalkulačkou) a spolehlivost \(1-\alpha\) (95 % → α = 0,05).
  2. Řádek tabulky: odhaduji μ, nebo σ²? Je σ zadané?
  3. Kvantil (ν = n − 1): 95 % → \(t_{0{,}975}(n-1)\); pro σ² oba \(\chi^2_{0{,}975}\) a \(\chi^2_{0{,}025}\).
  4. Dosaď: dolní a horní mez. Pro σ odmocni meze σ².
  5. Odpověď: „S pravděpodobností 0,95 leží μ v (… ; …).“
μ, σ neznámé\(\bar x \pm t_{1-\alpha/2}(n-1)\,\frac{s}{\sqrt n}\)
μ, σ známé\(\bar x \pm u_{1-\alpha/2}\,\frac{\sigma}{\sqrt n}\)
σ²\(\left(\frac{(n-1)s^2}{\chi^2_{1-\alpha/2}(n-1)},\ \frac{(n-1)s^2}{\chi^2_{\alpha/2}(n-1)}\right)\)

Pozor: větší kvantil χ² dává dolní mez. Jednostranný interval: kvantil \(1-\alpha\) místo \(1-\alpha/2\).

S7/1 n = 10, \(\bar x = 9{,}5\), s = 10,17, \(t_{0{,}975}(9) = 2{,}262\): \(9{,}5 \pm 2{,}262\cdot\frac{10{,}17}{\sqrt{10}} = 9{,}5 \pm 7{,}27\) → (2,23; 16,77). S7/2 σ², n = 9: \(\left(\frac{8 s^2}{17{,}535};\ \frac{8 s^2}{2{,}180}\right)\).

12 · Test hypotézy: kroky K1–K5

  1. K1 Hypotézy. \(H_0\): parametr = hodnota (\(\mu = 100\), \(\mu_1 = \mu_2\)). \(H_1\) podle otázky: „liší se / differs / is correlated“ → ≠ · „less, cheats (dává méně)“ → < · „greater, effective (před − po > 0)“ → >.
  2. K2 Kritérium. Vyber vzorec z oddílu 13, dosaď, vyjde jedno číslo T.
  3. K3 Rozdělení T za \(H_0\) a stupně volnosti ν (poslední sloupec v 13).
  4. K4 Kritický obor (kvantil z tabulek):
    ≠: zamítám, když \(|T| \ge t_{1-\alpha/2}(\nu)\), tj. \(t_{0{,}975}\)
    <: zamítám, když \(T \le -t_{1-\alpha}(\nu)\), tj. \(-t_{0{,}95}\)
    >: zamítám, když \(T \ge t_{1-\alpha}(\nu)\), tj. \(t_{0{,}95}\)
    (u, χ², F stejně; ν > 120: t ≈ u, 1,960 / 1,645).
  5. K5 Závěr. T v kritickém oboru → „\(H_0\) zamítáme na hladině α, platí \(H_1\)“; jinak „\(H_0\) nezamítáme“ (neznamená, že platí). Napiš větou v kontextu: „výrobce nešidí“, „lék je účinný“.

Interval ↔ test: \(\mu_0\) mimo 95% interval ⇔ oboustranný test zamítá.

14 · χ² test dobré shody

  1. \(H_0\): data jsou z Po(λ) / No(μ, σ) / daných p (kostka). \(H_1\): nejsou.
  2. Odhad parametrů z dat, r = jejich počet: Po \(\lambda = \bar x\) (r = 1) · No \(\mu = \bar x\), σ ze středů tříd (r = 2) · dané p (r = 0).
  3. \(p_j\) každé třídy: Po \(\frac{\lambda^k}{k!}e^{-\lambda}\), krajní „≥ k“ = 1 − ostatní · No \(\Phi(u_{\text{horní}}) - \Phi(u_{\text{dolní}})\), krajní třídy do ±∞.
  4. Očekávané \(E_j = n p_j\). Je-li \(E_j < 5\), slouč třídu se sousední (i \(n_j\)).
  5. \(\chi^2 = \sum \frac{(n_j - E_j)^2}{E_j}\) (M+ sčítá), ν = k − 1 − r, k = počet tříd po sloučení.
  6. Jen vpravo: \(\chi^2 \ge \chi^2_{0{,}95}(\nu)\) → zamítám.

15 · Kolmogorovův–Smirnovův test

  1. Kumulativní relativní četnosti: \(F_n(x_j) = \frac{n_1 + \dots + n_j}{n}\).
  2. Teoretická \(F_0(x_j)\): Po \(p(X \le x_j)\) (CD); spojité: F v horní hranici třídy.
  3. \(D = \max_j |F_n(x_j) - F_0(x_j)|\) (sloupec rozdílů, vyber největší).
  4. \(D \ge D_n(\alpha)\) → zamítám; n > 40: \(D_n(0{,}05) \approx 1{,}36/\sqrt n\).

S8/4 D = 0,0425 < \(1{,}36/\sqrt{71} = 0{,}161\) → nezamítáme.

16 · Regresní přímka \(\hat y = a + bx\)

  1. Kalkulačkou: Statistics → y=a+bx → zadej x, y → OPTN → Regression Calc: a, b, r. Ručně: součty \(\sum x, \sum y, \sum x^2, \sum xy\) (\(\sum y^2\) pro r).
  2. \(b\) ze vzorce, pak \(a = \bar y - b\bar x\).
  3. Předpověď: \(\hat y_0 = a + b x_0\).
\[ b = \frac{n\sum xy - \sum x\sum y}{n\sum x^2 - (\sum x)^2},\qquad a = \bar y - b\bar x \] \[ r = \frac{n\sum xy - \sum x\sum y}{\sqrt{\left(n\sum x^2 - (\sum x)^2\right)\left(n\sum y^2 - (\sum y)^2\right)}} \]

\(r^2\) = podíl vysvětleného rozptylu; přímka jde bodem \([\bar x, \bar y]\); x podle y je jiná přímka.
