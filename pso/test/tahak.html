Fráze: exactly k \(X=k\) · at least k \(X\ge k = 1-p(X\le k-1)\) · at most / not more than \(X\le k\) · more / less than \(>,<\) · none \(X=0\) · at least one \(1-p(0)\) · either A or B \(A\cup B\) · given that \(p(\cdot\mid\cdot)\) · with / without replacement → Bi / H · confidence 0,95 → α = 0,05 · significance level 95 % (S8/3) → α = 0,05.

1 · Klasická pravděpodobnost

  1. Jeden výsledek = co přesně padne / se vytáhne. 2 kostky = uspořádaná dvojice (36), i „two same dice“; 3 kostky = trojice (216). Tah k karet naráz = k-tice bez pořadí.
  2. Všechny výsledky n (záleží na pořadí? tahy po sobě / různé pozice → ano, naráz → ne; vracím?): k z n bez pořadí \(\binom{n}{k}\) · s pořadím \(\frac{n!}{(n-k)!}\) · s vracením \(n^k\) · seřazení \(n!\).
  3. Příznivé m počítej stejným způsobem jako n. j dobrých z M a zbytek z ostatních: \(\binom{M}{j}\binom{N-M}{k-j}\).
  4. \(p = m/n\). „Aspoň jeden“ → \(1 - p(\text{žádný})\). Tahy po jednom bez vracení → násob zlomky: 2 králové \(\frac{4}{32}\cdot\frac{3}{31} = \frac{3}{248}\).

Součet 2 kostek s: počet dvojic \(6 - |s-7|\) (s = 2…12: 1, 2, 3, 4, 5, 6, 5, 4, 3, 2, 1); součet 4 nebo 5: \(\frac{3+4}{36}\). Součet 3 kostek: vypiš trojice \(a \ge b \ge c\) se součtem s, každou počítej 6× (vše různé), 3× (dvě stejné), 1× (tři stejné), děl 216.

\(p(\bar A) = 1 - p(A)\) · \(p(A \cup B) = p(A) + p(B) - p(AB)\) · \(p(A \mid B) = \frac{p(AB)}{p(B)}\) · nezávislé: \(p(AB) = p(A)\,p(B)\)

2 · Geometrická pravděpodobnost

  1. Každé náhodné číslo = jedna osa (x, y). Ω = čtverec / obdélník, spočítej jeho plochu (\(|p|, |q| \le 1\) → strana 2, plocha 4).
  2. Každou podmínku přepiš na „y < …“: \(x+y<1\) → \(y<1-x\); \(xy<c\) → \(y<c/x\); reálné kořeny \(x^2+px+q\): \(p^2 - 4q \ge 0\) → \(q \le p^2/4\).
  3. Nakresli hranice a vyšrafuj, kde platí všechny podmínky.
  4. Průsečíky hranic: polož je rovné (\(1-x = 0{,}09/x\) → \(x^2 - x + 0{,}09 = 0\)).
  5. Plocha = \(\int (\text{horní} - \text{dolní})\,dx\), po úsecích mezi průsečíky.
  6. \(p = \) plocha / plocha Ω.

Kruh: \(p = (r/R)^2\); HW1/1 bod blíž než d/4 od středu: \(\left(\frac{d/4}{d/2}\right)^2 = \frac14\). Bod ve čtverci mimo vepsaný kruh (HW1/5): \(1 - \frac{\pi}{4} = 0{,}215\).

3 · Úplná pravděpodobnost, Bayes

  1. Hypotézy \(H_i\) = odkud věc je (skupina, krabice, stroj). Zapiš \(p(H_i)\); součet musí být 1 (účasti 60/50/70 % → \(p(H_1) = 0{,}6/1{,}8\)…; náhodně 1 z m krabic → \(1/m\)).
  2. Zapiš \(p(A\mid H_i)\) = pravděpodobnost jevu A uvnitř skupiny i.
  3. Úplná p.: pro každou větev \(p(H_i)\cdot p(A\mid H_i)\), pak sečti.
  4. Bayes („A nastalo, z které skupiny?“): moje větev / součet z kroku 3.
\[ \begin{aligned} p(A) &= \sum_i p(H_i)\,p(A\mid H_i) \\ p(H_k\mid A) &= \frac{p(H_k)\,p(A\mid H_k)}{p(A)} \end{aligned} \]

S1/6 p(A) = 0,17; \(p(H_1\mid A) = 0{,}441\) · HW1/2 \(\sum_{i=1}^{20}\frac{1}{20}\cdot\frac{i}{20} = 0{,}525\) (\(\sum_{i=1}^n i = \frac{n(n+1)}{2}\))

A dřív než B (opakuji, dokud nenastane A nebo B): \(\frac{p(A)}{p(A)+p(B)}\), S1/4: \(\frac{4}{4+6}\).
Střídání (začíná A; A vyhraje v hodu s p. a, B s p. b; kolo bez vítěze \((1-a)(1-b)\)): \(p_A = \frac{a}{1-(1-a)(1-b)}\), \(p_B = 1 - p_A\) (HW2/1: \(a = \frac16\), \(b = \frac26\) → 3/8, 5/8). Monty Hall: změnit 2/3, ponechat 1/3.

Bayes přes nekonečně hypotéz (HW2/2: N černých + 1 bílá)

  1. \(H_k = \{N = k\}\): \(p(H_k) = \frac{e^{-1}}{k!}\), \(p(B\mid H_k) = \frac{1}{k+1}\) (bílá je 1 z k + 1).
  2. \(p(B) = \sum_k \frac{e^{-1}}{(k+1)!} = e^{-1}(e-1)\), protože \(\sum_{k\ge0}\frac{1}{(k+1)!} = e - 1\) (\(e^x = \sum \frac{x^k}{k!}\)).
  3. \(p(N=k\mid B) = \frac{e^{-1}/(k+1)!}{e^{-1}(e-1)} = \frac{1}{(e-1)(k+1)!}\).

4 · Diskrétní náhodná veličina

  1. Tabulka \(x_i \mid p_i\), kontrola \(\sum p_i = 1\). Dvě neznámé p: soustava \(\sum p_i = 1\) a \(\sum x_i p_i = EX\).
  2. Tahy do úspěchu bez vracení: \(p(k)\) = součin „neúspěch · … · neúspěch · úspěch“, ve zlomcích ubývá koulí.
  3. F(x) = p(X < x) po intervalech: \(x \le x_1\): 0 · \(x_1 < x \le x_2\): \(p_1\) · \(x_2 < x \le x_3\): \(p_1+p_2\) · … · za \(x_{\max}\): 1.
  4. Z F zpět: \(p(X=k)\) = skok v k · \(p(X<a) = F(a)\) · \(p(X\ge a) = 1 - F(a)\) · \(p(a\le X<b) = F(b) - F(a)\).
  5. EX, DX (kalkulačka: Statistics, Freq = \(p_i\) → \(\bar x\) = EX, \(\sigma_x^2\) = DX):
\[ \begin{aligned} EX &= \textstyle\sum x_i p_i, \qquad EX^2 = \sum x_i^2 p_i \\ DX &= EX^2 - (EX)^2, \qquad \sigma = \sqrt{DX} \end{aligned} \]

\(E(aX+b) = aEX + b\) · \(D(aX+b) = a^2 DX\) · \(E(X+Y) = EX+EY\); nezávislé \(D(X+Y) = DX+DY\)

Které rozdělení?

  • Pevný počet n pokusů, X = počet úspěchů: s vracením / „probability p“ → Bi; z N kusů (M dobrých) bez vracení → H.
  • Průměrný počet za čas / plochu → Po, λ přepočítej na délku intervalu (20/h → 5 min: λ = 5/3). n ≥ 30, p ≤ 0,1 → Bi ≈ Po(np).
  • X = počet „pokračuji“ před koncem (může být 0: dny včas, správné odpovědi) → Ge od 0, p = P(pokračuji). S2/2: \(p(n) = (\frac14)^n\cdot\frac34\).
  • X = číslo pokusu, kdy to nastane (min. 1) → Ge od 1, p = P(té události).
  • Nejvýš n pokusů → useknutá Ge: \(p(k) = q^{k-1}p\) pro k < n, poslední \(p(n) = q^{n-1}\) (S3/3: \(0{,}85^5\)).
  • Předepsané pořadí („2. a 4. hod“) → jen součin, bez \(\binom{n}{k}\) (S2/7: \((\frac56)^3(\frac16)^2\)).

6 · Spojitá náhodná veličina

  1. Konstanta a: \(\int f\,dx = 1\) přes úsek, kde \(f \ne 0\) → rovnice pro a. „Prove density“: \(f \ge 0\) a \(\int f = 1\).
  2. Pravděpodobnost: \(p(a<X<b) = \int_a^b f\,dx\) (< a ≤ je jedno) = \(F(b) - F(a)\); \(p(X>c) = 1 - F(c)\).
  3. F(x) po částech: vlevo od úseku 0 · na úseku \(\int_{\text{začátek}}^{x} f(t)\,dt\) · vpravo 1. f ze 2 kusů: na 2. kusu \(F(x) = F(\text{konec 1. kusu}) + \int_{\text{začátek 2. kusu}}^{x} f_2\). Kontrola: na hranicích navazuje, na konci 1.
  4. EX, DX: \(EX = \int x f\), \(EX^2 = \int x^2 f\) (u kusů součet integrálů), \(DX = EX^2 - (EX)^2\). Symetrická f → EX = střed.
  5. Medián / kvantil: vyřeš \(F(\tilde x) = 0{,}5\) / \(F(x_p) = p\) (SOLVE).

7 · Normální rozdělení No(μ, σ)

A) Hodnota x → pravděpodobnost

  1. Zapiš μ a σ (σ = √variance!).
  2. Normuj: \(u = \frac{x-\mu}{\sigma}\) (na 2 desetinná místa pro tabulku).
  3. \(p(X<x) = \Phi(u)\) · \(p(X>x) = 1-\Phi(u)\) · \(p(a<X<b) = \Phi(u_b) - \Phi(u_a)\) · záporné u: \(\Phi(-u) = 1 - \Phi(u)\) · \(p(|U| < u) = 2\Phi(u) - 1\).

  1. Urči p pro tvar \(p(X<x) = p\):
    · „pod x / below“ s γ → p = γ (below 0,02 → 0,02)
    · „nad x / above“ s γ → p = 1 − γ (above 0,01 → 0,99; p(U > u) = 0,8 → 0,2)

9 · Náhodný vektor (X, Y)

  1. Konstanta: \(\iint f\,dx\,dy = 1\).
  2. Marginální: \(f_X(x) = \int f(x,y)\,dy\) (integruj přes y), \(f_Y(y) = \int f(x,y)\,dx\); mimo oblast 0.
  3. Nezávislost: platí \(f = f_X\,f_Y\) všude? Ano → nezávislé.
  4. p(G): nakresli oblast; vnější meze čísla, vnitřní závisí na vnější proměnné; spočítej vnitřní integrál první. Obdélník a \(f = g(x)h(y)\) → součin dvou integrálů.
  5. cov, ρ: \(E(XY) = \iint xy f\), \(\text{cov} = E(XY) - EX\,EY\), \(\rho = \frac{\text{cov}}{\sigma_X\sigma_Y}\).

S6/5 \(f = 4x(1-y)\) na \(⟨0,1⟩^2\): \(f_X = \int_0^1 4x(1-y)\,dy = 2x\), \(f_Y = 2 - 2y\) → \(f = f_X f_Y\), nezávislé. (b) \(\int_{1/2}^{3/4} 2x\,dx\cdot\int_{1/2}^1 (2-2y)\,dy = \frac{5}{16}\cdot\frac14 = \frac{5}{64}\); (c) \(\frac14\cdot\frac14 = \frac{1}{16}\); (d) \(p(Y\le X) = \int_0^1\!\int_0^x 4x(1-y)\,dy\,dx = \int_0^1 (4x^2 - 2x^3)\,dx = \frac56\).

10 · Výběrové charakteristiky

\[ \bar x = \frac{\sum x_i}{n},\quad s^2 = \frac{\sum (x_i - \bar x)^2}{n-1} = \frac{\sum x_i^2 - (\sum x_i)^2/n}{n-1} \]

Kalkulačka Statistics 1-Variable: \(s_x\) = s (dělí n − 1), \(\sigma_x\) dělí n. Četnosti \(n_j\) do sloupce Freq (středy tříd \(x_j\); otevřená krajní třída jako by měla stejnou šířku: 2,5 a 27,5): \(\bar x = \frac{\sum x_j n_j}{n}\), \(\sigma^2 = \frac{\sum x_j^2 n_j}{n} - \bar x^2\).

14 · χ² test dobré shody

  1. \(H_0\): data jsou z Po(λ) / No(μ, σ) / daných p (kostka).
  2. Odhad parametrů z dat, r = jejich počet: Po \(\lambda = \bar x = \frac{\sum x_j n_j}{n}\) (r = 1) · No \(\mu = \bar x\), σ ze středů tříd (oddíl 10, r = 2) · dané p (r = 0).
  3. \(p_j\) každé třídy: Po \(\frac{\lambda^k}{k!}e^{-\lambda}\); krajní třídy pokryjí vše: „≤ 2“ = p(0) + p(1) + p(2) (i s nulou!), „≥ 7“ = 1 − p(0) − … − p(6) · No: \(u\) hranic, \(p_j = \Phi(u_{\text{horní}}) - \Phi(u_{\text{dolní}})\), krajní třídy do ±∞ (Φ = 0 / 1).
  4. Očekávané \(E_j = n p_j\) (kontrola: \(\sum E_j = n\)). Je-li \(E_j < 5\), slučuj krajní třídu se sousední (sečti \(p_j\) i \(n_j\)), dokud všechna \(E_j \ge 5\).
  5. \(\chi^2 = \sum \frac{(n_j - E_j)^2}{E_j}\) (tabulka: třída, \(n_j\), \(p_j\), \(E_j\), člen), ν = k − 1 − r, k = počet tříd po sloučení.

15 · Kolmogorovův–Smirnovův test

  1. Kumulativní relativní četnosti: \(F_n(x_j) = \frac{n_1 + \dots + n_j}{n}\).

16 · Regresní přímka \(\hat y = a + bx\)

  1. Kalkulačka Statistics y=a+bx → a, b, r. Ručně: součty \(\sum x, \sum y, \sum x^2, \sum xy\) (\(\sum y^2\) pro r).
  2. \(b\) ze vzorce, pak \(a = \bar y - b\bar x\); předpověď \(\hat y_0 = a + b x_0\)
\[ b = \frac{n\sum xy - \sum x\sum y}{n\sum x^2 - (\sum x)^2},\qquad a = \bar y - b\bar x \] \[ r = \frac{n\sum xy - \sum x\sum y}{\sqrt{\left(n\sum x^2 - (\sum x)^2\right)\left(n\sum y^2 - (\sum y)^2\right)}} \]

\(r^2\) = podíl vysvětleného rozptylu; přímka jde bodem \([\bar x, \bar y]\).
