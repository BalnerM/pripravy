1 · Jevy, kombinatorika

\(p(\bar A) = 1 - p(A)\) · \(p(A \cup B) = p(A) + p(B) - p(AB)\) · \(p(A \mid B) = \frac{p(AB)}{p(B)}\) · nezávislé: \(p(AB) = p(A)p(B)\)

Výběr k z n: bez pořadí \(\binom{n}{k}\) · s pořadím \(\frac{n!}{(n-k)!}\) · s opakováním \(n^k\) · permutace \(n!\) · j dobrých z M a zbytek z N − M: \(\binom{M}{j}\binom{N-M}{k-j}\)

  1. Popiš 1 výsledek (kostky = uspořádaná dvojice, 36).
  2. Všechny n a příznivé m stejně (oboje s pořadím / bez).
  3. \(p = m/n\); „aspoň 1“ = 1 − p(žádný); tahy bez vracení: \(\frac{4}{32}\cdot\frac{3}{31}\).

Geometrická: každé číslo = osa, Ω čtverec; podmínky → \(y < 1-x\), \(y < c/x\), \(D \ge 0\); nakreslit, průsečíky, plocha (integrál po částech) / plocha Ω. Kruh: poměr \(r^2\).

2 · Úplná pravděpodobnost, Bayes

\[ \begin{aligned} p(A) &= \sum_i p(H_i)\,p(A\mid H_i) \\ p(H_k\mid A) &= \frac{p(H_k)\,p(A\mid H_k)}{p(A)} \end{aligned} \]
  1. \(H_i\) disjunktní, \(\sum p(H_i) = 1\)! Účasti 60/50/70 % → \(p(H_i) = 0{,}6/1{,}8\)…
  2. \(p(A\mid H_i)\) = úspěšnost ve skupině.
  3. Strom: násob po větvi, sečti větve s A; Bayes = moje větev / součet.

A dřív než B: \(\frac{p(A)}{p(A)+p(B)}\) (S1/4: \(\frac{4}{4+6}\)). Střídání, začíná A: \(p_A = \frac{a}{1-(1-a)(1-b)}\). Monty Hall: změnit → 2/3. Bayes s \(p(N=k)\) (HW2/2): \(p(N=k\mid B) = \frac{p(N=k)\,p(B\mid N=k)}{\sum_j p(N=j)\,p(B\mid N=j)}\), \(\sum \frac{x^k}{k!} = e^x\).

3 · Diskrétní náhodná veličina

\(F(x) = p(X < x)\): na \((x_i, x_{i+1}\rangle\) je \(F = p_1 + \dots + p_i\); pro \(x \le x_1\) 0, za max 1.

\(p(X = k)\) = skok v k · \(p(X < a) = F(a)\) · \(p(X \ge a) = 1 - F(a)\) · \(p(a \le X < b) = F(b) - F(a)\)

\[ \begin{aligned} EX &= \textstyle\sum x_i p_i, \qquad EX^2 = \sum x_i^2 p_i \\ DX &= EX^2 - (EX)^2, \qquad \sigma = \sqrt{DX} \end{aligned} \]

\(E(aX+b) = aEX + b\) · \(D(aX+b) = a^2 DX\) · \(E(X+Y) = EX+EY\); nezávislé \(D(X+Y) = DX+DY\)

2 neznámé p: \(\sum p_i = 1\) a \(\sum x_i p_i = EX\) → soustava. Tahání do 1. červené: násob \(\frac{b}{N}\cdot\frac{b-1}{N-1}\cdots\frac{r}{\cdot}\).

13 · χ² test dobré shody

  1. \(H_0\): X ~ Po(λ) / No(μ, σ) / dané p.
  2. Odhad z dat: Po \(\lambda = \bar x\) (r = 1); No \(\mu = \bar x\), σ ze středů tříd (r = 2); dané p (kostka) r = 0.
