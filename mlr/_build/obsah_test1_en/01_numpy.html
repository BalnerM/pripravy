Reading NumPy code

In the test, code is read, not run: “Read code without running it. np is NumPy; indices start at zero.” Almost every task (polynomial features, ridge, tree votes, forward selection) stands on a few lines of NumPy. If you can say the shape of the result and what the axis does from memory, half the points are safe. This chapter is a phrasebook of the idioms from the samples and labs 1–6, plus a method for tracing code on paper.

Array shape and the data convention

Definition: array shape

The shape (X.shape) is a tuple with the number of elements along each axis. In this course a data matrix always has shape (n_samples, n_features): row = sample, column = feature. A vector (1D array) has shape (n,) – it is neither a row nor a column.

the first number says how many measurements (leaves, patients) there are, the second how many quantities we measure on each. “X has shape (3, 2)” means 3 samples and 2 columns.

Definition: axis

The axis argument selects the axis along which a function (sum, mean, argmax …) works; this axis disappears from the result. For a matrix, axis=0 runs over the rows (one result per column) and axis=1 runs over the columns (one result per row).

axis=1 = “compute it in each row separately” – e.g. the mean vote of all trees for one sample. axis=0 = “in each column separately” – e.g. the mean of one feature over all samples (what standardization does).

How to remember axis

Matrix (4, 3): mean(axis=1) removes axis 1 (columns) → shape (4,), one number per row. mean(axis=0) removes axis 0 (rows) → shape (3,), one number per column. Just look at which number of the shape disappears.

How to recognise it and what to do: tracing code on paper

Recognise it by: Write the matrix X, give both resulting lists, explain axis=1, explain the dimensional error.

  1. Write the shape of every variable ((3,), (3, 2)…). The shape tells you more than the values.
  2. Go line by line and write the actual values – for small arrays all of them, for big ones only the shape.
  3. For @ check the inner sizes: (a, b) @ (b, c) → (a, c). If they do not match, it is the “dimensional error”.
  4. For axis say which axis disappears and what the result therefore means (“one number per sample”).
  5. Watch zero-based indexing: “position 1” is the second element.

Tasks

Task 1: axis and a mask
a = np.array([[1, 2, 3],
              [4, 5, 6]])
print(a.shape)
print(a.sum(axis=0))
print(a.mean(axis=1))
print(a[:, 1], a[1])
print(a[a > 2])

Write every printed value.

Look for: shape 2 × 3, two different axes, a mask. Result: (2, 3); [5 7 9]; [2. 5.]; [2 5] and [4 5 6]; [3 4 5 6].

Step-by-step solution
  1. a.shape = (2, 3) – two rows, three columns.
  2. sum(axis=0) removes the rows → sum of each column: 1+4, 2+5, 3+6 = [5, 7, 9].
  3. mean(axis=1) removes the columns → mean of each row: (1+2+3)/3 = 2, (4+5+6)/3 = 5 → [2., 5.] (a mean is always a float).
  4. a[:, 1] = all rows, column with index 1 (the second) → [2, 5]; a[1] = second row [4, 5, 6].
  5. a > 2 gives the mask [[F, F, T], [T, T, T]]; a[mask] picks values row by row: [3, 4, 5, 6].
Task 2: * versus @
A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 1], [1, 0]])
P = A * B
Q = A @ B

Write P and Q.

Result: \(P = \begin{bmatrix} 0 & 2 \\ 3 & 0 \end{bmatrix}\), \(Q = \begin{bmatrix} 2 & 1 \\ 4 & 3 \end{bmatrix}\) (Q has the columns of A swapped).

Step-by-step solution

1. Element-wise: numbers in the same place are multiplied.

\[ P = \begin{bmatrix} 1\cdot 0 & 2\cdot 1 \\ 3\cdot 1 & 4\cdot 0 \end{bmatrix} = \begin{bmatrix} 0 & 2 \\ 3 & 0 \end{bmatrix} \]

2. Matrix product: element (i, j) = row i of A times column j of B.

\[ Q = \begin{bmatrix} 1\cdot 0 + 2\cdot 1 & 1\cdot 1 + 2\cdot 0 \\ 3\cdot 0 + 4\cdot 1 & 3\cdot 1 + 4\cdot 0 \end{bmatrix} = \begin{bmatrix} 2 & 1 \\ 4 & 3 \end{bmatrix} \]
Task 3: shapes in linear regression

X has shape (100, 3) (rows are samples), y has shape (100,), w has shape (3,). Give the shapes of X.T, X.T @ X, X.T @ y, X @ w, X @ X.T and np.eye(X.shape[1]).

Result: (3, 100), (3, 3), (3,), (100,), (100, 100), (3, 3).

Step-by-step solution
  • X.T: the sizes swap → (3, 100).
  • X.T @ X = (3, 100) @ (100, 3) → (3, 3): its size is the number of features, not samples.
  • X.T @ y = (3, 100) @ (100,) → (3,).
  • X @ w = (100, 3) @ (3,) → (100,): one prediction per sample.
  • X @ X.T = (100, 3) @ (3, 100) → (100, 100) – the matrix of the dual form (one row per sample).
  • np.eye(X.shape[1]) = np.eye(3) → (3, 3), matches X.T @ X.
Task 4: argmax, argsort, unique
s = np.array([0.3, 0.9, 0.1, 0.9])
print(np.argmax(s), np.argsort(s))
labels = np.array(["b", "a", "b", "c", "b"])
values, counts = np.unique(labels, return_counts=True)
print(values, counts, values[np.argmax(counts)])

Write the printed values.

Trap: argmax returns a position, the first one on ties. Result: 1, [2 0 1 3]; ['a' 'b' 'c'], [1 3 1], 'b'.

Step-by-step solution
  1. The maximum 0.9 is at positions 1 and 3; argmax returns the first → 1.
  2. argsort sorts the indices by value: 0.1 (index 2), 0.3 (index 0), 0.9 (index 1), 0.9 (index 3) → [2, 0, 1, 3].
  3. unique returns the sorted distinct values ['a', 'b', 'c'] and counts [1, 3, 1].
  4. argmax(counts) = 1 → values[1] = 'b'. This is how lab 2 votes in k-NN.
Task 5: lists, pop and remove
remaining = [1, 3, 4]
selected = [0]
f = remaining.pop(1)
selected.append(f)
print(f, selected, remaining)

Write the printed values. Then rewrite the update using remove instead of pop.

Result: 3 [0, 3] [1, 4]. Variant: f = remaining[1]; selected.append(f); remaining.remove(f).

Step-by-step solution

pop(1) removes the element at position 1 (value 3) and returns it. remove(3) would remove the element with value 3 – you first have to read it with remaining[1]. A mistake like remaining.remove(1) would remove the value 1, i.e. a completely different feature. This is exactly what task B4 tests (chapter 5).

Task 6: comparison, astype and accuracy
p = np.array([0.2, 0.5, 0.7, 0.9])
y_hat = (p > 0.5).astype(int)
y_true = np.array([0, 1, 1, 1])
acc = np.mean(y_hat == y_true)

Write y_hat and acc.

Trap: 0.5 > 0.5 is False. Result: y_hat = [0, 0, 1, 1], acc = 0.75.

Step-by-step solution
  1. p > 0.5 → [False, False, True, True] (strict inequality, 0.5 does not pass).
  2. astype(int) → [0, 0, 1, 1].
  3. Matches with [0, 1, 1, 1]: [T, F, T, T]; mean = 3/4 = 0.75.
Task 7: rng.choice with and without replacement
rng = np.random.default_rng(0)
idx = rng.choice(6, size=6, replace=True)   # returned [2, 0, 2, 5, 1, 2]
X_b, y_b = X[idx], y[idx]

a) Which rows of X are in the sample, and how many times? b) Which rows are left out? c) What would change with replace=False?

Result: row 2 three times, rows 0, 1, 5 once; rows 3 and 4 left out; without replacement it would only be a permutation of all six rows.

Step-by-step solution
  1. np.unique(idx) = [0, 1, 2, 5] – four distinct rows, row 2 three times.
  2. Left out (out-of-bag): rows 3 and 4.
  3. With replace=False and size=6 each index is picked exactly once – just a shuffled order, no diversity for bagging.
  4. The same idx for X and y keeps feature–label pairs together.
Common traps
  • Zero-based indexing: “position 1” is the second element, X[:, 1] is the second column.
  • * is not the matrix product. Use @ for matrices.
  • shape[0] vs. shape[1]: rows (samples) vs. columns (features). Ridge needs np.eye(X.shape[1]).
  • argmax returns a position, not a value – and the position in the list it was called on.
  • Strict inequality: > 0.5 for exactly 0.5 gives False (a tie with an even number of voters).
  • A mean is a float: mean returns 2., not 2.
What to write for full points

Always give the shape and the meaning: “axis=1 averages across the columns (trees) of each row, so the result has one value per sample, shape (4,).” Write the whole matrix, not just a few entries; for lists give both resulting values.

In a nutshell

Row = sample, column = feature; axis is the axis that disappears; @ multiplies matrices, * elements; argmax gives a position.

Summary

A data matrix has shape (n_samples, n_features). Functions with axis work along the chosen axis and that axis disappears from the result: axis=0 gives a value per column, axis=1 a value per row. The matrix product @ needs matching inner sizes, * multiplies element-wise. argmax and argsort return indices, np.unique(..., return_counts=True) is used for voting, rng.choice(..., replace=True) for bootstrap. When tracing code, write the shape and the values of every variable.

Take-home messages

  1. Write the shape of every variable before computing values.
  2. axis = the axis that disappears from the result.
  3. (a, b) @ (b, c) → (a, c); X.T @ X has the size of the number of features.
  4. argmax = position (first on ties), not the value or the original feature number.
  5. Indices start at zero, range(3) = 0, 1, 2.

Test questions

The vote matrix V has shape (4, 3) – rows are samples, columns are trees. What shape does V.mean(axis=1) have and what does it mean?

Shape (4,): for each sample the mean vote of the three trees, i.e. the fraction of trees voting for class 1.

Why is X.T @ X a small matrix even for a million samples?

Its shape is (d, d), where d is the number of columns (features). The number of samples is “summed out” in the inner dimension.

What does np.argmax([0.7, 0.9, 0.9]) return and why?

1 – the position of the first maximum. On ties the first occurrence wins.

What is the difference between lst.pop(1) and lst.remove(1)?

pop(1) removes the element at position 1 and returns it; remove(1) removes the first element with value 1 and returns nothing.

What does np.column_stack([np.ones(3), x]) do for x = [1, 2, 3]?

It builds a (3, 2) matrix with a column of ones and a column x: rows [1, 1], [1, 2], [1, 3] – the design matrix of a line with an intercept.

When is (a > 0.5).astype(int) equal to 1 and when 0?

1 only for values strictly greater than 0.5; exactly 0.5 gives 0.
